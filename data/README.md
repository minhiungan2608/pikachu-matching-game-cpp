# Demo media

The included images are numbered tiles, plain backgrounds, and bitmap button labels.
The WAV effects are synthesized tones; the looping soundtrack file is silent.

Regenerate them with `python3 scripts/generate_demo_assets.py` (Python standard library only).
No external artwork, audio recordings, or font files are needed.

The relative `pokemon_icon` / `pokemon_screen` folder names are retained for compatibility
with the game's asset loader. Their contents are generic demo graphics.
